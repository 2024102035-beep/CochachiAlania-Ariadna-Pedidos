# Sistema de Gestion de Pedidos - Comercial Cochachi Alania Ariadna
#Autora: Cochachi Alania Ariadna

## Descripcion

Proyecto desarrollado para gestionar el calculo de importes de los pedidos de Comercial NovaTech.

El sistema permite calcular el subtotal de los pedidos segun el precio unitario y la cantidad solicitada.

## Lenguaje de programacion

Python 3.
